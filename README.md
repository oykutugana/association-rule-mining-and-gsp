## How to Run

1. Place the raw dataset at `data/dataset_son.csv`
2. Open `data_mining_homework.ipynb` in Jupyter Lab or Jupyter Notebook
3. Run all cells in order — each section is self-contained

---

## Key Parameters

| Parameter | Value | Description |
|-----------|-------|-------------|
| TOP_N_PRODUCTS | 5,000 | Top products by frequency |
| USER_SAMPLE_RATE | 0.15 | 15% random user sample |
| MIN_SUPPORT | 0.005 | Minimum itemset support |
| MIN_CONFIDENCE | 0.15 | Minimum rule confidence |
| MIN_LIFT | 1.5 | Minimum rule lift |
| GSP min_support | 0.01 | Minimum sequence support |
| GSP max_gap | 15 days | Maximum gap between orders |
